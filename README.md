# HU Call Blocker

Magyar nyelvű, reklámmentes hívásvédelmi alkalmazás Android 10 vagy újabb rendszerre. Internetkapcsolat és felhasználói fiók nélkül működik.

## Főbb funkciók

- Külföldi, nemzetközi előhívójú hívások automatikus blokkolása.
- Magyar (+36) számok és engedélyezett névjegyek átengedése.
- Országonként beállítható kivételek.
- Saját engedélyezett és tiltott telefonszámok kezelése.
- Az utolsó 100 blokkolt hívás naplózása országjelzéssel, zászlóval és a tiltás okával.
- Gyors engedélyezés vagy tiltás közvetlenül a naplóból.
- Kapcsolható védelem, állapotsori jelzés és animált védelmi áttekintés.
- Automatikus világos és sötét megjelenés az Android rendszerbeállítása alapján.

A működéshez engedélyezni kell az Android hívásszűrési szerepkörét. A saját tiltólista elsőbbséget élvez. Az országfelismerés a hívószám számozási tervén alapul, nem a hívó tényleges tartózkodási helyén.
